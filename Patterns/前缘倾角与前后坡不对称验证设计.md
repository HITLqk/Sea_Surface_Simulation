# 前缘倾角与前后坡不对称验证设计

## 1. 验证目标

本轮不再把卷浪水平、垂向尺寸作为核心通过条件，只验证两种相对稳定的形态特征：

1. 成熟卷浪是否形成合理的陡峭前缘；
2. 波形是否呈现前坡陡、后坡缓的非对称结构。

尺寸参数仅保留在原始数据中，不进入本轮统计图和联合通过率。

## 2. 统一局部波形定义

从卷浪中心传播剖面提取有序参数曲线

`r(s) = [u(s), z(s)]`。

必须按变形前传播坐标的节点顺序保存曲线，不能按变形后的 `u` 重新排序，否则悬垂段会被破坏。

在卷浪作用窗外估计局部平均水位 `z_m`。以局部波峰 `C=(u_c,z_c)` 为起点，沿曲线向传播方向和反传播方向分别寻找第一个平均水位交点：

- 前零交叉点 `F=(u_f,z_m)`；
- 后零交叉点 `R=(u_r,z_m)`。

定义波峰高度和前后水平长度：

`h_c = z_c-z_m`

`L_f = |u_f-u_c|`

`L_r = |u_c-u_r|`

若某一侧不存在交点，或长度小于两个网格间隔，该样本记为无效，不允许用边界点替代。

## 3. 前缘倾角

### 3.1 数学定义

在波峰传播侧的连续下降分支上，选择

`0.2 <= (z-z_m)/h_c <= 0.8`

的点。对于悬垂曲线，只保留与前零交叉点连通的前缘分支。对这些点进行总最小二乘直线拟合，即对中心化坐标矩阵

`Q = [u-mean(u), z-mean(z)]`

作奇异值分解，取第一主方向 `v=[v_u,v_z]`，定义

`theta_f = atan2(|v_z|,|v_u|)`。

总最小二乘不要求 `z` 是 `u` 的单值函数，适合存在悬垂的卷浪剖面，也比单点导数稳定。

### 3.2 参考指标

Erinin et al. 2023 在对齐到射流撞击时刻的弱、中、强 plunging breakers 中报告约 `65.3 deg`、`67.6 deg` 和 `66.3 deg`。本研究采用 `65-70 deg` 作为成熟前缘的实验包络，但不要求其随卷浪强度单调变化。

这一参考只适用于与实验相近的成熟射流/撞击前时相。普通无卷浪海面的前坡角可以用相同算法计算，但不与该包络作物理等价解释。

## 4. 前后坡不对称度

### 4.1 数学定义

采用 Kjeldsen-Myrhaug 局部波形定义：

`epsilon_f = h_c/L_f`

`epsilon_r = h_c/L_r`

定义前后坡不对称度

`A_fr = epsilon_f/epsilon_r = L_r/L_f`。

解释为：

- `A_fr = 1`：前后对称；
- `A_fr > 1`：前坡比后坡陡；
- `A_fr < 1`：波峰向后倾斜，不符合本文传播方向下的典型卷浪形态。

该指标由零交叉几何得到，与前缘局部拟合角使用不同的波形区域，避免两个指标完全重复。

### 4.2 参考方式

已有实验给出的 crest-front steepness 范围受破碎机制影响较大。Kjeldsen-Myrhaug 总结的宽范围约为 `0.32-0.78`；Bonmarin 对 plunging breakers 给出的典型 crest-front steepness 约为 `0.61`。因此：

1. 分别报告 `epsilon_f` 和 `epsilon_r` 的分布；
2. 核心判断为 `P(A_fr>1)` 及其置信区间；
3. `A_fr = 1.6-2.35` 只能作为由前后坡经验范围推得的辅助包络，不能写成 Bonmarin 直接报告的普适范围；
4. 不把单个样本是否落入该窄包络作为模型成败标准。

## 5. 实验组别

采用三个仿真组和两个外部参考，不再把每个卷曲参数设成独立实验组。

| 组别 | 设置 | 作用 |
|---|---|---|
| G0 No-breaking | 非线性随机海面，不施加显式卷曲 | 检查普通海面是否接近对称、前缘角较小 |
| G1 Shallow-curl ablation | 旧配置，`verticalAngleRatio` 约 `0.20-0.40` | 证明仅水平前伸不足以形成成熟前缘和不对称卷浪 |
| G2 Proposed | 冻结后的修正参数域 | 验证本文模型的统计形态 |
| R1 Erinin | `theta_f=65.3/67.6/66.3 deg` | 成熟前缘倾角参考 |
| R2 Bonmarin/Kjeldsen-Myrhaug | crest-front steepness 及非对称规律 | 前后坡关系参考 |

G0、G1、G2 必须采用配对随机试验：相同随机种子、海况、网格和被选波峰，只改变卷曲机制。每组至少 `N=100` 个有效样本。G2 内部连续随机抽取参数，不把不同参数值拆成几十个小组。

## 6. 标定集与验证集

此前用于选择修正参数域的数据属于标定集，不能再次作为最终验证结果。参数域冻结后，使用全新随机种子生成验证集：

- 标定集：只用于确定 G2 参数范围；
- 验证集：G0/G1/G2 各至少 100 个配对样本，禁止继续调参；
- 若验证后再次修改模型，必须重新生成新的验证集。

这项试验验证的是随机海面和参数扰动下的稳定性。由于参考包络参与过模型约束，论文中应称为“reference-constrained morphology validation”，不能称为完全独立外部验证。

## 7. 统计量与论文图

每组报告：

- `theta_f` 的中位数、四分位范围和 `65-70 deg` 包络覆盖率；
- `epsilon_f`、`epsilon_r` 和 `A_fr` 的中位数及 95% bootstrap 置信区间；
- `P(A_fr>1)`；
- 相对于 G0 的中位数差及 bootstrap 置信区间。

不建议只报告显著性 `p` 值；组间差异应同时给出效应大小。

论文仅保留一张双子图：

1. `theta_f` 的抖动散点/箱线分布，叠加 `65-70 deg` 参考带；
2. `A_fr` 的抖动散点/箱线分布，标出对称线 `A_fr=1`，辅助显示经验包络。
