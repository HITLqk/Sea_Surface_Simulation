# NRCS 两条响应曲线的实验设计

## 1. 验证目标

NRCS 部分只保留两条响应曲线：

1. 固定风速时的 NRCS-观测角曲线 `sigma0(gamma)`；
2. 固定观测角时的 NRCS-风速曲线 `sigma0(U10)`。

两条曲线都需要独立实测数据或独立经验参考。G0/G1 之间的比较只能证明卷浪模块的增量作用，不能代替绝对 NRCS 验证。

## 2. 最小实验组

每个子图只展示三个数据系列：

| 系列 | 定义 | 作用 |
|---|---|---|
| Reference | 与频率、极化、风速、观测角和风向方位匹配的实测 NRCS；若暂时没有实测，可用独立 GMF/文献数据并明确标注 | 绝对量级和趋势参考 |
| G0 No-breaking | 非线性 Elfouhaily 海面，不触发显式卷浪 | 配对消融基线 |
| G1 With-breaking | 与 G0 相同背景海面和随机种子，按物理判据触发本文卷浪，并计算遮蔽和局部面元散射 | 完整模型 |

Reference 用离散标记和误差棒表示，G0/G1 用两条曲线和 95% 置信区间表示。这样图中视觉上仍只有两条仿真曲线。

不再增加“浅卷浪”中间组。否则一幅 5 页 Letter 的平均散射图承担不了清晰的机理解释。

## 3. 公共实验条件

建议先锁定本文应用场景，再根据可获得的实测数据微调共同区间：

- 雷达频率：X 波段，优先使用实际系统中心频率，例如 `9.65 GHz`；
- 极化：HH；
- 风向相对方位：固定为上风向 `0 deg`，除非实测数据对应其他方位；
- 海水介电常数、温度和盐度：所有组保持一致；
- 波龄和谱参数：同一比较点保持一致，并与参考海况尽量匹配；
- NRCS 定义：按单位水平投影面积归一化；
- 角度定义：全文优先使用擦地角 `gamma`。若参考给出从天顶方向计算的入射角 `theta_i`，统一换算为 `gamma = 90 deg - theta_i`；
- 每个条件点使用相同的一组随机种子进行 G0/G1 配对蒙特卡洛；
- 每个条件点建议至少 `100` 组，计算量允许时使用 `200` 组；
- 所有平均先在线性域完成，最后转为 dB，禁止直接平均 dB 值。

平均 NRCS 采用

```text
sigma0_dB = 10 log10[sum(sigma_i) / A_ground]
```

其中 `sigma_i` 为所有可见、被照射面元的线性散射截面，`A_ground` 为固定仿真区域的水平面积。G0/G1 必须使用相同面积、面元散射核和雷达参数。

## 4. 曲线一：NRCS-观测角

### 固定条件

- `U10 = 10 m/s`，使海况中存在足够的破碎事件，同时不过度偏向极端海况；
- X 波段 HH；
- 上风向观测；
- 波龄、显著波高和其他环境参数固定。

### 自变量

观测角范围以匹配实测数据为第一原则。若面向本文低至中等擦地角对海雷达，建议优先使用：

```text
gamma = 2, 4, 6, 8, 10, 12, 15, 20 deg
```

不能把面向 SAR 的 `20-60 deg` 入射角直接当成擦地角使用。

### 希望检验的现象

- G0 应给出背景海面的基本角度衰减趋势；
- G1 在卷浪容易产生朝向雷达的陡峭面元及遮蔽变化的角度区间，应比 G0 更接近 Reference；
- G1 不应在所有角度上产生近似恒定的 dB 平移，否则说明改善主要来自人为增益，而不是几何角度响应。

## 5. 曲线二：NRCS-风速

### 固定条件

- 固定擦地角建议先取 `gamma = 10 deg`，最终应以实测雷达的代表角度为准；
- X 波段 HH；
- 上风向观测；
- 其他雷达参数固定。

### 自变量

```text
U10 = 5, 7.5, 10, 12.5, 15 m/s
```

这组采样同时覆盖弱破碎、转折和较明显破碎海况。如果参考数据更密，可在相同区间内增加采样点。

### 希望检验的现象

- 低风速时物理触发的卷浪很少，G1 应接近 G0；
- 随风速增加，卷浪数量或面积占比应由触发判据自然增加，G0/G1 差异逐渐出现；
- G1 对 Reference 的改善应主要出现在中高风速段，而不是在每个风速强制插入相同数量、相同尺寸的卷浪。

## 6. NRCS 实验不能沿用形态验证的条件筛选

形态验证中的 G2 为了证明模型能够生成目标形态，会保留前缘倾角和不对称度落入指定区间的样本。这种条件筛选不能用于总体平均 NRCS：它会过度选择高波峰和特定朝向，使平均散射产生选择偏差。

NRCS 实验应采用无偏场景生成：

1. 先生成随机非线性背景海面；
2. 对所有候选波峰执行相同物理触发判据；
3. 触发则生成卷浪，不触发则该次 G1 与 G0 保持相同；
4. 不因为最终 NRCS 或几何指标不理想而丢弃样本；
5. 记录每个条件点的破碎事件密度和破碎面积占比，作为解释变量，但不必另画正文图。

当前 Curl 示例采用“从 32 m x 32 m 海面中选择一个高峰并生成一个卷浪”的方式，适合形态展示，不适合直接代表单位海域平均 NRCS。进入编码前，需要先把它改成由触发率决定单位面积卷浪数量的场景生成器。

## 7. 散射机制边界

第一版 NRCS 验证建议只检验本文已经能够清楚归因的机制：

- 卷浪几何导致的局部法向变化；
- 水平投影面积变化；
- 可见性与自遮蔽；
- 与 G0 相同的面元 NRCS 核。

不要为了让 G1 靠近 Reference，额外加入可调的常数白沫增强项。若后续必须建模泡沫或破碎非 Bragg 散射，应给出独立物理参数和数据来源，并明确它是新增散射机制，而不是卷浪几何验证的一部分。

当前 TSC 模块本身是经验散射核。若 Reference 也直接由同一个 TSC 公式生成，就会形成自我验证。Reference 必须来自实测或独立模型。

## 8. 统计指标与结论判据

正文只保留一个主要误差指标：

```text
RMSE = sqrt(mean[(sigma0_sim_dB - sigma0_ref_dB)^2])
```

分别报告 `RMSE_angle` 和 `RMSE_wind`，并计算

```text
Delta_RMSE = RMSE_G0 - RMSE_G1
```

`Delta_RMSE > 0` 表示加入卷浪后更接近参考。论文中的有效结论应同时满足：

1. G1 在两条曲线上的 RMSE 均不高于 G0；
2. 风速曲线中，G1-G0 差异随破碎活动增强而增大；
3. 角度曲线中，G1 的改善具有角度选择性，而不是常量平移；
4. G1 的置信区间和 Reference 的不确定度被明确展示。

## 10. 编码前必须先确定的输入

1. 最终采用哪一套独立 NRCS 实测或文献数据；
2. 该数据的频率、HH/VV、角度定义、风向方位和 `U10` 高度；
3. 本文雷达的实际中心频率和代表性擦地角；
4. 是否只验证卷浪几何散射，还是还要加入独立的白沫/破碎散射项。

在这四项没有锁定前，不应先调参数画出“好看的”NRCS 曲线。
