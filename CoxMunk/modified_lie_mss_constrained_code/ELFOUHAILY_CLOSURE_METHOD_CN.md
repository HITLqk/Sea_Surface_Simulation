# 修正 Lie 海面的 Elfouhaily 统计约束方法

## 1. 为什么需要约束

修正 Lie 变换用于引入波峰尖锐化、峰谷不对称等非线性几何特征，但二阶变换也会改变坡度谱能量。若不加控制，非线性海面的均方坡度（MSS）可能偏离成熟的风浪谱统计。因此，应对变换后的二阶坡度统计进行约束，但不能把 Cox-Munk 等待验证规律直接写进每个样本，否则验证会变成循环论证。

## 2. 本次采用的约束逻辑

约束遵循 Elfouhaily 模型的统计参数化思想：用总体谱矩和随风速平滑变化的低维参数描述统计规律，而不是让每个随机实现精确等于经验曲线。

1. 使用与验证组相同的 `U10=1:1:10 m/s` 风速网格。
2. 使用独立标定种子 `101:112` 生成未经约束的修正 Lie 海面；正式验证使用不重叠的种子 `1:20`。
3. 对每个风速计算标定样本的顺风、横风 MSS 中位数。
4. 以代码中完整二维 Elfouhaily 谱的数值积分结果为目标，分别计算顺风和横风缩放比。
5. 在归一化 `log(U10)` 上对两个缩放比的对数做二次多项式拟合，得到全局平滑函数 `s_u(U10)` 和 `s_c(U10)`。
6. 验证阶段同一风速的所有新样本使用相同缩放系数，保留样本间随机散布，不逐样本贴合任何经验值。

频域中使用正值角向修饰

```text
|G(phi)|^2 = exp(lambda_0 + lambda_2 cos(2 phi))
```

实现顺风和横风两个统计缩放。该操作不改变 Fourier 相位，因此尽量保留 Lie 变换产生的非线性波峰几何。

## 3. 方向性如何修正

方向性指标定义为 `gamma = sqrt(MSS_cross / MSS_along)`。本方法不直接指定 `gamma`，而是分别约束顺风与横风谱矩，使 `gamma` 作为两者比值自然产生。这样避免直接把 TGRS 的 `0.864` 或 `0.84` 写进模型。图中灰色虚线是约束前的修正 Lie，橙色曲线是约束后结果，可以直接观察方向性修正量。

完整实验中，约束前 `gamma` 为 `0.7682-0.8381`，约束后为 `0.7760-0.8405`，恢复了随风速总体上升并趋于平缓的趋势，消除了旧结果低风速约 `0.95` 的异常值。

## 4. 为什么 Cox-Munk 验证仍然成立

Cox-Munk、Guérin IASI 和 TGRS/Hu 均未参与约束系数拟合，只作为外部参照。约束目标仅为生成模型自身采用的 Elfouhaily 二维谱积分，而且系数由独立标定样本估计。因此正式验证集不可能被逐点强制落在这些经验规律上。

约束后与 Elfouhaily 的 RMSE 为 `0.000195`，但与 Cox-Munk、Guérin、TGRS/Hu 的 RMSE 仍分别为 `0.005072`、`0.004354` 和 `0.003173`。这些非零差异正是后续验证需要报告的内容。

## 5. 结果边界

这是一种顺风/横风二阶谱矩闭合，用来防止 Lie 变换注入不受控的坡度能量；它不是对完整波数-方向谱逐点反演，也不能单独证明卷浪几何正确。后续仍需用坡度 PDF、高阶矩、峰谷不对称、破碎判据和雷达 RTI 对非线性与卷浪结构进行独立验证。
