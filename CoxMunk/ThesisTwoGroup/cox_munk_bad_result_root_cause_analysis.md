# Cox-Munk 两组验证效果不佳的原因分析

## 一、总体判断

当前结果不好并不是单纯的绘图问题，也不能通过继续调整 `modifiedLieScale` 解决。主要问题有三层：

1. **验证对象定义不成立**：`Modified Lie Breaking` 实际上只是单值高度场上的二阶非线性修正，并没有生成可识别的卷浪或破碎区域。
2. **图像与统计指标不是同一个海面**：MSS 包含多尺度短波，而效果图只显示主波网格。
3. **参考量的尺度与物理含义没有统一**：Cox-Munk、Guérin、TGRS/Hu 与当前 Elfouhaily 积分使用的有效波数范围不同，而且三套参考本身也不完全一致。

因此，当前实验最多说明“多尺度 Elfouhaily 统计合成是自洽的”和“二阶 Lie 项会提高主波段 MSS”，不能说明已经成功构建和验证了卷浪。

## 二、最严重的问题

### 1. `Modified Lie Breaking` 并没有真正生成卷浪

代码最终仍然得到单值函数 `z = h(x,y)`：

```matlab
Hnonlinear = H + Lstar;
breakingSurface = real(ifft2(Hbreaking))*N^2;
```

它没有：

- 水平坐标映射 `(X,Y) -> (X',Y')`；
- 局部翻卷、悬垂或多值几何；
- 破碎触发判据；
- 卷浪区域掩膜；
- 破碎后的耗散或能量再分配。

因此图 3 中橙色曲线只是波峰和波谷略有非对称，不能形成几何意义上的 overturning/breaking wave。把这一组命名为 `Breaking` 会使验证结论超过代码实际能力。

### 2. 效果图与 MSS 统计使用的不是同一个表面

总 MSS 为：

```matlab
realization.linear = add_mss(linearMss,shortMss);
realization.breaking = add_mss(breakingMss,shortMss);
```

但效果图仅由 `Hlinear` 或 `Hbreaking` 生成，不包含任何短波 tile：

```matlab
realization.linearSurface = real(ifft2(Hlinear))*N^2;
realization.breakingSurface = real(ifft2(Hbreaking))*N^2;
```

短波对总 MSS 的平均占比如下：

| `U10` | Linear 短波占比 | Modified Lie 短波占比 |
|---:|---:|---:|
| 1 m/s | 54.4% | 54.2% |
| 3 m/s | 66.3% | 64.9% |
| 5 m/s | 74.1% | 70.9% |
| 7 m/s | 79.7% | 74.7% |
| 10 m/s | 85.2% | 77.5% |

也就是说，`10 m/s` 效果图没有显示决定约 80% 总 MSS 的短波内容。图像看起来几乎相同，而 MSS 曲线明显分离，并不是矛盾，而是因为它们描述的根本不是同一个尺度完整的海面。

### 3. 不同风速下效果图的空间尺度发生了变化

主波网格使用：

```matlab
kp = g*(age/U10)^2;
dk = kp/primaryPeakSamples;
L = 2*pi/dk;
```

因此物理区域长度与 `U10^2` 成正比。图 3 中：

- `5 m/s` 海面约为 `272 m x 272 m`；
- `10 m/s` 海面约为 `1089 m x 1089 m`；
- 两者却都使用 `256 x 256` 网格。

所以 `10 m/s` 的空间步长约为 `5 m/s` 的四倍。两幅图不能直接比较卷曲程度，因为观察范围和物理分辨率都不同。

## 三、参考曲线不匹配的原因

### 4. `maximumOpticalWavenumber = pi*1000` 缺少物理依据

当前代码将 Elfouhaily MSS 积分到约 `3142 rad/m`。MSS 对高波数非常敏感，实际敏感性计算为：

| 最大波数 | `U10=3` | `U10=5` | `U10=10` |
|---:|---:|---:|---:|
| 100 rad/m | 0.02116 | 0.02525 | 0.03535 |
| 370 rad/m | 0.02390 | 0.02985 | 0.04910 |
| 1000 rad/m | 0.02511 | 0.03304 | 0.05898 |
| 3142 rad/m | 0.02525 | 0.03341 | 0.06012 |

在 `10 m/s` 时，仅改变积分截止就会使 MSS 从 `0.0491` 变成 `0.0601`。Cox-Munk、Guérin 和 Hu 在该风速约为 `0.054`。因此当前高风速偏差很大一部分来自任意截止波数，而不是随机海面合成错误。

正确做法应先确定各观测模型对应的有效尺度或仪器响应，再对 Elfouhaily 谱施加匹配的波数窗函数，而不是让一个固定的 `pi*1000` 同时对照所有实测规律。

### 5. 三套参考规律本身不能被一条曲线同时严格满足

例如方向性指数：

- TGRS 跨模型平均约为 `0.864`，其模拟海面典型值约为 `0.84`；
- 当前录入的 Guérin 数据在 `3-5 m/s` 给出约 `0.94-0.95`；
- 当前线性 Elfouhaily 为约 `0.81-0.83`。

Guérin 与 TGRS 的差异已经大于许多仿真组间差异。因此不能把“同时贴合 Guérin 散点、TGRS 0.864 和 Elfouhaily 方向扩展”定义为唯一通过条件。

此外，TGRS 2024 的核心贡献是广义坡度 PDF 与方向性指数。代码中的 `TGRS/Hu` 总 MSS 实际采用的是论文汇总并选用的 Hu 分段关系，不是 Gao 等人重新拟合的一条独立 MSS 实测规律。

### 6. 低风速 Elfouhaily 参数被人为截断

在 `U10` 较低时，短波平衡系数 `alphaM` 会变成负数。代码采用：

```matlab
alphaM = max(alphaM,0);
```

这保证了 PSD 非负，但也意味着 `1-2 m/s` 使用的已经不是原始连续参数化。固定逆波龄 `0.84` 对所有风速也未必代表同一类真实海况，尤其无法描述低风速背景涌浪和 Cox-Munk 侧风截距中的残余坡度。

## 四、修正 Lie 实现中的问题

### 7. 当前算子不是论文公式的直接实现

代码为了保持 Hermitian 对称，将风速投影改为：

```matlab
windX = U10*abs(KX)./K;
windY = U10*abs(KY)./K;
```

这是一个额外的建模假设。它改变了原式的符号和方向结构，却没有给出物理推导或基准实验。与此同时，`cfg.windDirectionDeg` 只进入 Elfouhaily 方向扩展函数，并没有进入修正 Lie 算子，所以该算子并未真正随任意风向旋转。

### 8. 非线性强度没有物理标定

`modifiedLieScale = 1.0` 只是固定值。代码在所有风速、所有位置施加二阶项，没有根据以下物理量触发：

- 局部波陡；
- 波峰曲率；
- 相速度与流体质点速度比；
- breaking crest length；
- 白冠覆盖率或破碎概率。

所以它必然会提高整体主波段斜率，但这种提高不等价于“只在应当破碎的位置生成卷浪”。`10 m/s` 时卷浪组比 Linear 总 MSS 高约 `10%`，方向性却由约 `0.84` 降到约 `0.79`，正说明当前算子更像全场顺风锐化，而不是局部破碎模型。

## 五、统计与绘图层面的问题

### 9. Cox-Munk 验证只重点展示总 MSS

代码已经计算 `AlongMedian` 和 `CrossMedian`，但主图只画 `TotalMedian`。总量接近可能掩盖顺风偏高、侧风偏低的问题。方向性图只能显示两者的比例，不能替代分量误差图。

应至少分别展示：

- along-wind MSS；
- cross-wind MSS；
- total MSS；
- `gamma`；
- 相对误差或标准化残差。

### 10. 使用中位数对比基于均值/方差定义的经验关系

Cox-Munk MSS 和谱积分本质上是期望二阶矩，当前却用 20 次实现的中位数计算 RMSE。由于当前散布较窄，影响不算最大，但统计定义不完全一致。更合理的是用 ensemble mean 作为主估计，同时报告置信区间；中位数和 IQR 可作为稳健性补充。

### 11. RMSE 没有明确通过阈值

当前只给出绝对 RMSE，没有：

- 相对误差；
- 参考模型不确定区间；
- 风速分段误差；
- 预先规定的通过标准。

因此“RMSE 更小”只能做组间排序，不能据此宣布模型通过或失败。

### 12. 效果图不适合展示卷浪

二维高程热图会隐藏波峰前后非对称、局部垂直面和坐标折叠。中心剖面也只取一个固定截面，可能完全避开极端波峰。当前图只能展示高程纹理，不能作为卷浪存在的证据。

## 六、当前结果实际能说明什么

### 可以说明

1. 多尺度 Linear 组能够较好复现代码自身的 Elfouhaily 谱积分。
2. 当前二阶 Lie 项随风速增加而提高主波段 MSS。
3. 当前 Lie 项主要强化顺风斜率，使 `gamma` 在高风速下降。

### 不能说明

1. 已经生成真实卷浪或破碎浪。
2. 卷浪规律符合 Cox-Munk。
3. 模型同时符合 Cox-Munk、Guérin 和 TGRS。
4. 图 3 展示的是用于总 MSS 计算的完整多尺度海面。

## 七、建议的重新验证逻辑

1. **先验证 Linear 背景海面**：固定物理尺度与网格，明确波数窗函数，分别对照 along、cross、total MSS 和 `gamma`。
2. **把 Cox-Munk 与卷浪验证分开**：Cox-Munk 用于验证背景坡度统计，不作为卷浪是否真实的唯一判据。
3. **重新定义卷浪组**：使用局部破碎判据产生 mask，只在达到阈值的波峰应用几何卷曲或非线性修正。
4. **验证局部卷浪特征**：比较波陡尾部、曲率尾部、前后坡不对称、破碎面积率、breaking crest length 与经验规律。
5. **统一可视化尺度**：Linear 与 Breaking 必须使用同一物理窗口、同一空间分辨率、同一随机实现和同一颜色范围。
6. **最后再看整体 MSS 是否被破坏**：卷浪组不需要比 Linear 更贴 Cox-Munk，但其背景区 MSS 应保持合理，局部破碎区则用专门指标验证。

这套分层验证能够回答两个不同问题：Elfouhaily 背景海面是否正确，以及新增卷浪机制是否真实。当前代码把这两个问题混成一个总 MSS 曲线，正是效果缺乏说服力的根本原因。
