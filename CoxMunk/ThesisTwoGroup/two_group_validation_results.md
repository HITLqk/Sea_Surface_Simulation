# Elfouhaily 与修正 Lie 卷浪两组验证结果

## 1. 本次重新定义的组别

本实验不调用此前的四组验证代码，只保留两个待验证组：

1. **Linear Elfouhaily**：按 Elfouhaily 全向谱和方向扩展函数，通过线性频域过滤生成。
2. **Modified Lie Breaking**：与 Linear 组共享同一个随机海面，在主波频带额外施加论文第二章式 (2.31)-(2.33) 的二阶修正 Lie 项。

风速固定为 `U10 = 1:1:10 m/s`，每个风速使用 20 个配对随机实现。配对设计保证两组差异仅来自修正 Lie 项。

## 2. 采样设计

单一大网格无法同时覆盖千米尺度主波与毫米至厘米尺度短波，因此本实验采用多尺度频带合成：

- 主波网格取 `dk = kp/12`，满足论文式 (2.29) 隐含的 `dk <= kp/10` 谱峰采样要求；
- 主波网格用于生成可视化海面，并计算修正 Lie 非线性项；
- 更高波数采用独立倍频程微面元网格逐带随机合成，最高波数为 `pi*1000 rad/m`；
- 各频带的顺风和侧风斜率方差相加，得到完整 MSS。

这不是在结果曲线上添加确定性补偿，而是对每个短波频带实际生成随机 Fourier 系数并计算其斜率方差。

## 3. 修正 Lie 算子的解释

论文式 (2.31) 中的 `h_tx` 和 `h_ty` 按 Lie/Creamer 伪微分模型解释为二维 Hilbert/Riesz 分量，而不是普通空间导数。若误写为 `dh/dx` 和 `dh/dy`，低风速时会发生错误的高波数平方放大；小样本测试中 `1 m/s` 的总 MSS 曾因此达到约 `5.3`，明显不物理。

为保持频域海面满足 Hermitian 对称性，风向投影采用偶对称的投影幅值。否则式 (2.31) 中的奇对称实乘子会产生虚数高程分量。

## 4. 对照规律

- **Cox-Munk**：比较顺风、侧风和总 MSS。
- **Guérin IASI**：在其可用范围内比较，本实验覆盖 `3-10 m/s`。
- **Gao et al., IEEE TGRS 2024**：采用文中汇总并用于广义坡度模型的 Hu 总 MSS 分段规律，同时比较方向性指数 `gamma = sqrt(MSS_cross/MSS_along)`；文中跨模型均值约为 `0.864`，模拟海面典型值约为 `0.84`。
- **Elfouhaily 谱积分**：用于检查随机生成器是否正确复现自身输入谱，不能替代实测基准。

## 6. 评价

### Linear Elfouhaily

- 对自身 Elfouhaily 积分的 RMSE 仅为 `7.75e-4`，说明多尺度随机生成和 MSS 计算一致。
- `1-6 m/s` 与 TGRS/Hu 的总 MSS 趋势和量级较接近。
- `7-10 m/s` 开始高于 TGRS/Hu、Cox-Munk 和 Guérin；`10 m/s` 时约高 `12%-13%`。
- 方向性 `gamma` 随风速由约 `0.77` 增至 `0.84`，高风速端接近 TGRS 的模拟海面典型值 `0.84`。

因此，Linear 组通过了**生成器自一致性**，并基本再现了 TGRS 所述趋势，但不能宣称同时严格满足三套实测规律。

### Modified Lie Breaking

- 总 MSS 随风速单调增加，且相对 Linear 的增量随风速增大，符合高海况非线性逐渐增强的定性预期。
- `10 m/s` 时总 MSS 为 `0.06768`，比 Linear 高约 `10.6%`，并比三套实测/经验对照高约 `23%-25%`。
- `gamma` 在高风速下降至约 `0.79-0.81`，表明修正 Lie 项过多增强了顺风斜率；与 TGRS 的 `0.84/0.864` 对照相比偏低。

因此，Modified Lie 组目前只能判定为**趋势合理但定量验证未通过**。下一步不应再直接调 MSS，而应重新检查式 (2.31) 中风速投影的量纲、修正 Lie 强度与真实破碎面积率之间的物理关系，并使用卷浪局部判据单独约束非线性项。
