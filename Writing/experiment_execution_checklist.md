# 海面建模与雷达回波论文实验执行清单

## 1. 这批实验最终要证明什么

当前 `00_main.pdf` 的基本行文链条可以保留：

```text
环境参数
  -> 动态三维海面
  -> 破碎/卷浪与涌浪结构
  -> 面元几何及遮挡
  -> 雷达回波与 RTI
```

但实验必须分别证明以下四件事，不能再由几张外观图共同承担：

1. **背景海面正确**：给定风速和方向谱后，波谱、能量、MSS 与坡度分布合理。
2. **卷浪模块有效**：破碎触发有依据，卷浪尺度和几何统计合理，G1 的变化确实来自卷浪而非总能量增加。
3. **雷达映射可信**：面元、阴影和散射模型能够把几何变化转化为可解释的 RCS、Doppler 和相关性变化。
4. **最终输出接近实测**：相同测量条件下，G1 比 G0 和现代 baseline 更接近 NAV/IPIX 实测回波。

## 2. 固定组别，后续不要改名

| 代号 | 组别 | 用途 |
|---|---|---|
| `R_CM` | Cox-Munk/Breon-Henriot 经验关系 | 背景坡度统计参考，不是仿真算法 |
| `R_BG` | Guimaraes 黑海活动破碎斑块数据 | 卷浪斑块尺度与朝向统计参考 |
| `R_meas` | NAV X-band HH 凝视模式实测数据 | 最终回波真实性参考 |
| `B_new` | Random-Stokes 2022 全链路方法 | 现代外部 baseline |
| `G0` | 本文模型关闭 breaking/curling | 卷浪消融组 |
| `G1` | 本文完整 breaking + 3-D curling | 完整模型 |

所有 `G0/G1` 必须采用相同随机种子、背景谱、网格、风浪条件、雷达参数、噪声和信号处理链。关闭卷浪后如果还同时关闭阴影、涌浪或更换散射模型，就无法归因。

涌浪模块使用独立组别，不与 G0/G1 混在一起：

```text
S0 = swell factor e=0
S1 = swell factor e>0
```

- [ ] 标记目标污染、固定强散射、异常脉冲、低 CNR 距离单元和非平稳区段。

- [ ] 若只有两个 `staring.mat`，正文只能写“两个凝视记录/两个观测条件”，不能泛称“多海况充分验证”。

**输出：** `dataset_manifest.csv`、`data_split_manifest.csv`、每个记录的功率/RTI/Doppler 快速质检图。

### E02. 仿真可重复性与数值收敛

- [ ] 保存统一 `runId`、随机种子和完整配置快照。
- [ ] 同一配置重复运行，确认海面与回波文件逐项一致。
- [ ] 对局部卷浪网格至少运行三档分辨率，例如 `dx=0.10/0.05/0.025 m`。
- [ ] 对背景大场景至少运行两档分辨率，检查 PSD、MSS 和回波统计稳定性。
- [ ] 检查时间步长收敛，避免 Doppler 差异来自采样不足。
- [ ] 检查三角面法向、面积、可见性和背景面元扣除，避免局部卷浪与原背景重复计入面积。

**通过标准：** 两个最细网格之间，核心指标变化原则上应小于 5%；若达不到，继续加密或报告离散化不确定性。

## 4. 背景海面验证

### E03. 输入方向谱与能量守恒

**目的：** 先证明输入和输出谱正确，再讨论非线性和卷浪。

- [ ] 选择固定目标谱。建议主实验采用 Ryabkova2019 modified spectrum 或当前 Elfouhaily 谱，不能在 G0/G1 间更换。
- [ ] 风速建议取 `U10 = 3, 5, 7, 10, 12, 15, 18, 20 m/s`。
- [ ] 每个风速至少 30 个随机 realization；最终主点建议 50 个。
- [ ] 计算目标谱与生成表面恢复 PSD 的积分能量误差、谱峰频率误差和谱矩 `m0/m2/m4` 误差。
- [ ] 检查非线性变换前后输出谱差异，必要时使用 spectrum-matched 输入。
- [ ] 对方向扩展函数验证每个波数下的角向积分为 1。
- [ ] 单独验证涌浪乘性修正前后总能量守恒，不能只展示细长波峰图。

**输出图表：** 目标/恢复 PSD、谱矩误差表、能量误差随风速曲线。

**通过标准：** DSF 数值归一化误差达到积分容差；涌浪调制前后总能量相对误差建议小于 0.1%。非线性输出谱若有系统偏差，必须量化并采用匹配策略，不能隐去。

### E04. Cox-Munk 背景坡度验证

**组别：** `R_CM + B_new + G0 + G1_background-mask`。

- [ ] 从卷浪掩膜外的背景区域计算顺风、横风坡度。
- [ ] 报告 `MSS_u`、`MSS_c` 和总 MSS，不只报告总 MSS。
- [ ] 比较一维边缘坡度 PDF 和二维联合等概率轮廓。
- [ ] 计算 MSS NRMSE、Wasserstein 距离和 JS 散度。
- [ ] 对每个风速报告均值、95% bootstrap 置信区间和 realization 数。
- [ ] 另画“包含卷浪区域”的坡度尾部作为现象分析，但不把它混入 Cox-Munk 背景主验证。

**必要图表：** 一张 MSS-风速图、一张典型风速的二维坡度 PDF、一张误差表。

**禁止结论：** G1 落在 Cox-Munk 上下界内只能证明整体背景坡度未明显失真，不能证明卷浪几何真实。

### E05. 波形非线性基础检查

- [ ] 在固定目标谱下比较线性参考面、G0 和 G1 背景的高度 PDF、偏度、峰度。
- [ ] 计算 crest-trough asymmetry、crest front/back slope ratio、峰值曲率和最大坡度。
- [ ] 检查 G1 开启卷浪后，非卷浪背景的 `Hs`、PSD 和总能量没有被意外改变。
- [ ] 选取相同随机相位的剖面叠加，展示改变发生在触发区域而不是全场。

**作用：** 证明修改的 Lie/二阶海面确实产生预期非高斯波峰，而不是靠后处理旋转制造全部非线性。

## 5. 卷浪与破碎验证

### E06. 破碎触发判据验证

分两种声称选择实验强度。

**最低版本，仅验证机制一致性：**

- [ ] 记录每个波峰的判据量，例如 `u/c`、`||u||_m/c`、局部坡度或模型实际使用量。
- [ ] 做阈值上下扫描，确认低于阈值不触发、高于阈值触发。
- [ ] 报告触发率随风速、波陡和方向扩展的单调趋势。
- [ ] 检查 G0/G1 在触发前完全一致。

**强版本，若声称准确识别破碎：**

- [ ] 选择带 breaking/non-breaking 标签的实验或现场事件。
- [ ] 使用固定阈值，不在测试集上重新调参。
- [ ] 报告 TP、FP、TN、FN、precision、recall、F1 和 ROC/PR 曲线。
- [ ] 分别报告 2-D/3-D、深水/浅水、spilling/plunging 的适用范围。

Vargas2026 的 `-0.5g` 只在模型能输出可比拉格朗日加速度时使用；不能把高度场二阶空间导数当成粒子加速度替代。

### E07. 卷浪几何统计对比

**组别：** `R_BG + G0 + G1`，必要时增加 HOSM 小场景参照。

- [x] 已有 3 组固定参数、每组 40 个随机背景，共 120 个实例。
- [x] 已计算 footprint area、surface area ratio、有效长宽、垂向范围、长宽比和 overturned area fraction。
- [x] 已与 Guimaraes 聚合面元朝向曲线比较，并计算 IAE/Wasserstein。
- [x] 已完成雷达视角敏感性初步结果。
- [ ] 从“固定三档参数”升级为按同一海况下实测联合分布抽样，避免三个手工模板代表全部卷浪。
- [ ] 至少选择 3 个匹配 Guimaraes 的海况时段，而不是混合全部 20 个时段。
- [ ] 分别报告典型、中强和极端事件，当前大型卷浪只能作为尾部案例。
- [ ] 采用按事件 bootstrap 的置信区间，不能把同一事件的连续帧当成独立样本。

**主结论条件：** G1 应在多个几何指标上比 G0 更接近实测分布，并且不是仅靠扩大事件面积获得较好视觉效果。

### E08. 卷浪参数敏感性和稳健区间

- [x] 已有 `maxCurlDeg`、尺度等参数搜索基础结果。
- [ ] 对 `crestLength`、`crossWaveWidth`、`crestHeight`、`maxCurlDeg`、`pivotDepth`、`forwardLean` 和 mask threshold 做单因素或拉丁超立方采样。
- [ ] 每个参数组合至少运行 10 个随机相位，筛选后主组合再扩展到 30-50 个。
- [ ] 输出参数对面积、长宽比、垂向范围、翻卷比例和等效散射面积的敏感性排名。
- [ ] 给出稳定可用参数区间，而不是只报告一个“最佳”参数点。
- [ ] 参数选择仅使用 calibration 海况，最终误差在 held-out 海况上报告。

## 6. 涌浪模块验证，仅在正文保留该模块时执行

### E09. 方向扩展与涌浪实验

**组别：** `S0(e=0)`、`S1(e>0)`、目标方向谱或浮标方向谱。

- [ ] 选择至少三个涌浪因子和三个峰值波数/波龄条件。
- [ ] 验证角向积分能量守恒。
- [ ] 比较方向谱半功率宽度、方向集中度、主轴方向误差和低频/高频响应。
- [ ] 检查 `tanh(kp/k)` 是否只显著收窄低频分量，高频风浪不应被错误压窄。
- [ ] 若有 NAV/浮标方向谱，直接比较二维方向谱；若没有，只能称数学性质和可视化验证，不能称实测验证。
- [ ] 在回波层检查涌浪是否产生合理的低频调制，而不是人为周期条纹。

**去留规则：** 没有方向谱或可量化参照时，GRSL 正文建议删除该创新点，避免分散破碎海面主线。

## 7. 面元散射与局部雷达效应

### E10. 面元几何和散射模型单元验证

- [ ] 平面面元解析测试：面积、法向、擦地角和斜距必须与解析值一致。
- [ ] 单一正弦波测试：检查迎风/背风可见性及阴影边界。
- [ ] 准镜面项扫描：入射角、极化、频率和风速变化应符合 TSC 原模型趋势。
- [ ] 漫散射项扫描：检查低擦地角和不同方位下的连续性与数值范围。
- [ ] 检查 dB、线性功率、RCS 和 NRCS 单位转换。
- [ ] 对面元非相干求和的适用范围写入元数据，不将其称为相干全波电磁仿真。

### E11. G0/G1 配对局部散射增强

**组别：** 相同背景和面元索引下的 `G0/G1`。

- [ ] 生成每个卷浪事件的 `breakingMask` 和 `eventId`。
- [ ] 计算背景面积、卷浪真实曲面面积、可见面积、阴影面积和准镜面朝向面积。
- [ ] 计算 `DeltaSigma_B+`、等效增强面积 `A_B,eq` 和增益 `G_B`。
- [ ] 报告正增益和负增益，不能只保留 `[Delta sigma]+` 后隐藏因遮挡产生的损失。
- [ ] 扫描雷达相对方位、擦地角和极化，报告均值与置信区间。
- [ ] 分开运行“仅卷曲”“仅阴影”“卷曲+阴影”，明确两种机制贡献。
- [ ] 若 TSC 没有泡沫、多径和介电变化，只称“模型内几何散射增量”。

**必要图表：** 局部 RCS 差值图、`A_B,eq` 箱线图、方位/擦地角敏感性曲线。

## 8. 最终实测雷达验证

### E12. NAV 条件匹配的端到端仿真

**组别：** `R_meas + B_new + G0 + G1`。

- [ ] 对每个实测记录逐项匹配风速、风向、浪高、浪向、雷达频率、HH 极化、擦地角、PRF、距离分辨率和观测时长。
- [ ] 保存绝对标定版本和归一化版本。归一化版本验证纹理，绝对版本验证功率/RCS。
- [ ] B_new、G0 和 G1 使用相同目标谱与雷达链；若 B_new 无法更换原始 P-M 谱，结果必须单列。
- [ ] 每个实测条件至少生成 30 个 realization，主条件建议 50 个。
- [ ] 仿真参数只在 calibration 时间块确定，最终表格使用 held-out test。
- [ ] 不从实测测试块反推每个统计量后再宣称生成结果匹配。

### E13. 幅度分布与重尾直接比较

- [ ] 对 `R_meas/B_new/G0/G1` 使用相同幅度或功率定义、相同归一化和相同样本选择。
- [ ] 直接计算实测与仿真的 KS、Wasserstein、Bhattacharyya distance。
- [ ] 在 `CCDF=1e-3` 和样本量允许时的 `1e-4` 报告 threshold error。
- [ ] 报告 95%、99%、99.9% 分位数误差和 sea-spike rate。
- [ ] 分距离单元、分时间块报告稳定性，不能只合并全部样本。
- [ ] K、Weibull、Pareto、log-normal 等分布拟合仅作辅助，使用 MLE、AIC/BIC 和 AD/KS。
- [ ] 主问题始终是 `D(R_meas,G1) < D(R_meas,G0/B_new)`，不是“G1 最符合 K 分布”。

### E14. Doppler 与时空相关验证

- [ ] 计算 Doppler centroid、3 dB 带宽、谱偏度和谱 Wasserstein/JS 距离。
- [ ] 计算慢时间 ACF、decorrelation time 和非平稳滑窗变化。
- [ ] 计算距离维相关函数和 correlation length。
- [ ] 若数据允许，计算二维 range-Doppler 或时频谱。

- [ ] RTI 仅作为配套可视化，不再作为唯一证据。

## 10. 推荐执行顺序

## 11. GRSL 最小可发表实验包

如果篇幅和时间紧，正文至少保留以下五组结果：

1. **背景几何**：多风速 Cox-Munk MSS、坡度 PDF 与置信区间。
2. **卷浪几何**：Guimaraes matched-sea-state 几何分布，G0/G1 配对。
3. **卷浪雷达贡献**：局部 `A_B,eq/G_B` 与视角敏感性。
4. **实测回波**：NAV 条件下 `R_meas/B_new/G0/G1` 的分布、尾部、Doppler 和相关性表格。
5. **RTI 展示**：统一色标的代表性 RTI，加 sea-spike/轨迹统计，不再只做肉眼判断。

涌浪、HOS 和 AI 实验均可放补充材料或后续长文。若涌浪仍被列为主要创新，则 E09 从可选项升级为正文必需项。

## 14. 最重要的判断规则

实验完成后，只有同时满足以下关系，才足以支持本文完整方法：

```text
背景层：G0/G1 的非卷浪区域满足谱与 Cox-Munk 约束
卷浪层：G1 比 G0 更接近独立破碎几何/发生统计
雷达层：D(R_meas, G1) < D(R_meas, G0)
外部比较：D(R_meas, G1) <= D(R_meas, B_new)，或在物理可控性/外推性上有明确优势
```

如果只得到“G1 比 G0 的尾部更重”，不能直接写成“更真实”；必须证明该变化朝实测参考靠近，同时没有破坏谱能量、背景分布和 Doppler/相关性。
