# GRSL 五页 Letter 的精简验证指标

## 结论

删除极端杂波验证。正文只保留两个验证层面，每个层面两个指标：

1. 卷浪形态：前缘倾角、无量纲卷曲尺度；
2. 平均散射：NRCS 随入射角变化、NRCS 随风速变化。

这四项分别回答两个核心问题：生成的局部结构是否像真实 plunging breaker，以及生成海面的平均雷达散射是否符合实测规律。

## 1. 卷浪形态验证

所有形态量必须在同一时相提取：**卷浪射流充分形成、但尚未撞击前缘水面**。不同文献或仿真时相不能混合比较。

### 1.1 前缘倾角

- 指标：卷浪前缘局部切线与水平面的夹角 `theta_f`。
- 经典意义：它是卷浪前坡陡峭程度和前后不对称性的最直接表征，避免再同时列前坡、后坡和多个不对称系数。
- 主参考：Erinin et al., JFM, 2023 的弱、中、强 plunging breakers。
- 参考值：`65.3 deg`、`67.6 deg`、`66.3 deg`。
- Letter 中采用的参考范围：**65-70 deg**。
- 展示方式：一张实测轮廓与仿真轮廓叠加图，并在图中标出 `theta_f`；表格只报告仿真值、参考范围和绝对角度误差。

该范围是 Erinin 三组受控深水卷浪在指定撞击前时相的实验包络，不应表述为所有海况下的普适破碎判据。

### 1.2 无量纲卷曲尺度

- 指标：卷曲区域水平尺度 `r_x/lambda` 和垂向尺度 `r_y/lambda`，其中 `lambda` 为对应主波波长。
- 经典意义：直接验证模型产生的悬垂卷曲区域是否具有合理尺寸；它比内部的 `curlMultiplier` 等生成参数更具有物理可比性。
- 主参考：Erinin et al., JFM, 2023。
- 水平尺度参考范围：**`r_x/lambda = 0.049-0.069`**。
- 垂向尺度参考范围：**`r_y/lambda = 0.045-0.059`**。
- 可选派生量：`r_x/r_y = 1.08-1.17`，只在图注或补充说明中给出，不作为第五个验证指标。
- 展示方式：仍使用上一张轮廓叠加图标注 `r_x`、`r_y`，不额外增加新图。

## 2. 平均散射验证

平均散射统一使用归一化雷达散射截面

`sigma_0 = sigma/A`

并以 dB 表示。仿真和参考数据必须匹配频段、同极化方式、入射角定义、风向相对方位和风速高度。本文为 X 波段 HH 场景时，只选 X 波段 HH 参考数据；不混用 VV 或其他频段曲线。

### 2.1 NRCS-入射角曲线

- 指标：固定风速和方位角时的 `sigma_0(theta)`。
- 经典意义：这是验证海面平均后向散射模型最基本的角度响应。
- 建议自变量范围：按现有实测数据覆盖范围取值；用于经典 Bragg/复合面参照时优先采用**中等入射角 20-60 deg**。若论文使用擦地角，应先换算为入射角，不能直接混画。
- 参考：Plant 的海面 NRCS 实测汇总/复合面模型；也可使用与本文 X 波段 HH 条件严格匹配的实测数据。
- 量化误差：在共同角度采样点计算 `RMSE_theta`（dB）。
- 展示方式：一张曲线图，包含实测/经验参考、无卷浪组 G0、含卷浪组 G1；阴影表示多次随机实现的置信区间。

这里不设置人为的“合格 NRCS 数值范围”，因为 NRCS 的绝对值随频率、极化、风速、方位和入射角共同变化。正确做法是对匹配条件下的参考曲线计算 dB 误差。

### 2.2 NRCS-风速曲线

- 指标：固定入射角和方位角时的 `sigma_0(U_10)`。
- 经典意义：验证模型能否恢复平均散射随海面风速增强的实测响应。
- 建议风速范围：优先覆盖**`U_10 = 5-15 m/s`**，该范围与常用海面谱实测及现有中等海况数据较容易匹配；若现有雷达数据范围更窄，以实测共同区间为准。
- 参考：与本文频段、HH 极化及观测几何匹配的 Plant 海面 NRCS 数据或本项目实测雷达数据。
- 量化误差：在共同风速点计算 `RMSE_U`（dB）。
- 展示方式：与入射角响应组成同一幅双子图，仍只画参考、G0 和 G1。

## 3. 最小实验组与版面

只设置三条曲线：

- Reference：匹配条件的实验轮廓或实测 NRCS；
- G0：非线性海面，无显式卷浪；
- G1：非线性海面，加入本文卷浪模型。

形态验证中，G0 不具备 `r_x`、`r_y`，无需强行计算；它的作用是直观说明没有卷曲结构。平均散射中，G0 与 G1 在完全相同的风速、谱参数、雷达参数和随机种子下比较。

建议正文仅占：

- 图 1：参考与 G1 的卷浪轮廓叠加，标出 `theta_f`、`r_x` 和 `r_y`；
- 图 2：`sigma_0(theta)` 与 `sigma_0(U_10)` 两个子图；
- 表 1：三个形态量的参考范围、仿真值和误差。

不再验证后坡、波峰曲率、Bonmarin 多种不对称系数、三维展向变化、PDF/CCDF、峰度、偏度或海尖峰率。
