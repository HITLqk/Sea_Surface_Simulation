# 现代 MSS 验证代码实现结果

## 已实现

- Guérin 2023 表 1 的 25 组顺风/横风 MSS 实测数据；
- Cox-Munk 12.5 m 到 10 m 风速高度换算；
- Davis 2025 的总 MSS、aligned 和 crossing 参数化；
- `guerin` 与 `davis` 两套独立实验配置；
- 每次随机实现的原始散点输出；
- 中位数、四分位区间和 5%--95% 箱线输出；
- 按组计算的 RMSE 和 MAE；
- NonLiner 可选物理波数合成带，默认关闭，旧实验行为不变；
- 高风模式严格使用 `k=0.01-1 rad/m`，并进行区域长度、Nyquist
  波数和非线性输出截止检查。

## Smoke test

两种模式均完成一个风速、一个随机种子的端到端测试，包括海面生成、
三角面元 MSS、CSV/MAT 保存和 PNG 绘图。

### Guérin 模式，U10=3 m/s

| 组别 | total MSS |
|---|---:|
| Linear | 0.011145 |
| G0 Nonlinear | 0.011372 |
| G1 Upward | 0.011372 |
| G1 Background | 0.011371 |

卷浪只占约 `4.67e-5` 的顶点比例，因此一次局部理想卷浪对大区域全局
MSS 的影响很小。这是合理的几何消融结果，但不能代表真实破碎发生率。

### Davis 模式，U10=25 m/s

| 组别 | k=0.01--1 rad/m total MSS |
|---|---:|
| Linear | 0.020932 |
| G0 Nonlinear | 0.028708 |
| Davis 2025 reference | 约 0.018764 |

Linear 与 Davis 参考较接近；G0 当前高出约 0.00994。该差异被保留为
待验证的模型结果，没有对非线性增益做经验缩放。

## 对准备说明的修正

代码复查确认当前 NonLiner 已采用固定的 `6/12 rad/m` 二阶输入/输出
截止，并非继续与 Nyquist 相对绑定。此次修改新增的是独立的海面合成
波数带；Davis 模式再将二阶截止设置为 `0.5/1 rad/m`。因此原有低风
模型参数未被覆盖。
