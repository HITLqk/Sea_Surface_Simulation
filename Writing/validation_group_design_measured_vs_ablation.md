# Cox-Munk、海杂波分布与卷浪破碎判据的验证组设计

## 1. 结论先行

本文的三类验证不能共用同一种对照逻辑。最合理的做法是固定两组仿真实验，再按验证对象引入不同的外部参照：

- `G0：No-breaking`：本文模型关闭卷浪触发与卷曲变换，其余参数全部不变；
- `G1：With-breaking`：本文完整模型，开启卷浪判据、卷曲几何和相应散射计算；
- `R_C：Cox-Munk`：经验坡度统计曲线，不是第三组仿真；
- `M_R：Measured radar clutter`：与仿真雷达参数和海况相匹配的实测海杂波；
- `M_B：Measured breaking waves`：带有破碎/非破碎标签、波面剖面或速度场的波槽/野外数据。

三类验证对实测数据的需求如下。

| 验证项 | 必须使用的参照 | 是否必须另找原始实测数据 | 两组仿真能证明什么 | 两组仿真不能证明什么 |
|---|---|---:|---|---|
| Cox-Munk 坡度统计 | `R_C + G0 + G1` | 否 | 加入卷浪前后，整体坡度统计是否仍满足经验物理约束 | 卷浪形状是否真实、破碎位置是否正确 |
| 海杂波幅度分布 | `M_R + G0 + G1` | 是 | 卷浪模块如何改变幅度分布及重尾 | 没有 `M_R` 时，不能证明哪组更接近真实海杂波 |
| 卷浪判据的机制消融 | 文献阈值/物理规律 `+ G0 + G1` | 否 | 判据是否被正确触发、触发后是否产生预期几何和散射变化 | 判据能否正确识别真实破碎，生成的卷浪几何是否准确 |
| 卷浪判据与几何的物理验证 | `M_B +` 本文判据/模型 | 是，或至少使用公开实验数据 | 破碎识别、发生时刻和波峰几何是否与真实破碎一致 | 仅靠 `G0/G1` 无法完成该结论 |

因此，如果文章的核心表述是“建立了准确的卷浪海面模型”，推荐准备两类外部证据：一类实测雷达海杂波 `M_R`，用于分布和 RTI；一类波槽或野外破碎浪数据 `M_B`，用于破碎判据和卷浪几何。Cox-Munk 已经是由实测海面归纳出的经验基准，不需要再下载一套原始海面测量数据。

如果短篇版面或数据条件只允许一套原始实测数据，应优先保留 `M_R`，并把卷浪结论收窄为“满足已有破碎判据并改善雷达回波统计”，不要表述为“已验证卷浪几何与真实破碎过程高度一致”。

## 2. 两组仿真的统一定义

### 2.1 G0：No-breaking 消融组

G0 应当与完整模型共享以下内容：

- 相同海浪谱、方向谱、风速、风向和海域尺寸；
- 相同空间网格、时间步长和仿真时长；
- 相同随机相位或成对随机种子；
- 相同雷达频率、极化、擦地角、分辨率和散射模型；
- 相同归一化、距离衰减补偿和数据截取流程。

G0 只关闭卷浪触发、卷曲几何修正及由该区域引入的特殊散射项。这样 `G1-G0` 才能归因于卷浪模块。

### 2.2 G1：With-breaking 完整组

G1 开启全部卷浪过程，包括：

- 破碎候选波峰识别；
- 破碎判据或阈值；
- 卷曲/前倾/翻卷几何变换；
- 遮挡、自遮蔽、局部法向变化及相应散射计算；
- 如果模型包含泡沫或白冠散射，则同时开启，但需单独说明其参数来源。

### 2.3 重复试验

每个工况不能只生成一次随机海面。建议每个风速和海况至少使用 `N=30` 组成对随机实现，报告均值、标准差或 95% 置信区间。G0 与 G1 对每次重复使用相同随机种子，减少随机海面差异对卷浪效应估计的干扰。

## 3. Cox-Munk：不需要另找原始实测数据

### 3.1 它验证的对象

Cox-Munk 来源于太阳耀斑照片反演的真实海面坡度统计，可作为外部经验真值。它适合验证：

- 顺风向均方斜率 `MSS_u`；
- 横风向均方斜率 `MSS_c`；
- 总均方斜率 `MSS_t = MSS_u + MSS_c`；
- 均方斜率随风速 `U10` 的变化趋势；
- 可选：坡度 PDF 的偏度和峰度。

它不适合直接验证局部卷浪形态。Cox-Munk 统计包含真实海面的综合效应，但其观测量是全局坡度分布，并没有逐个标注卷浪位置、翻卷角度或破碎时刻。

### 3.2 推荐组别

| 曲线/组别 | 内容 | 作用 |
|---|---|---|
| `R_C` | Cox-Munk 顺风、横风和总 MSS 经验曲线或区间 | 外部物理基准 |
| `G0` | 无卷浪仿真 | 判断基础海面是否满足坡度统计 |
| `G1` | 有卷浪仿真 | 判断卷浪修正是否破坏整体统计 |

这里虽然图中有三条来源，但只有两组仿真实验。Cox-Munk 是参考曲线，不是需要重新采集的实测组。

### 3.3 指标与图表

对每个风速计算：

```text
RE_MSS(U10) = |MSS_sim(U10) - MSS_CM(U10)| / MSS_CM(U10)
```

建议报告：

- `MSS_u`、`MSS_c`、`MSS_t` 及 95% 置信区间；
- 相对 Cox-Munk 的 `RE_MSS`；
- `Delta_MSS = MSS_G1 - MSS_G0`，用于量化卷浪模块对整体粗糙度的扰动；
- 多风速曲线，而不是单一风速的柱状图。

正确的预期结论不应强求 G1 在所有风速下都比 G0 更接近 Cox-Munk。更稳妥的结论是：G0 和 G1 均保持合理的 MSS-风速关系，且 G1 在产生局部卷浪的同时没有显著破坏整体坡度统计。若 G1 确实降低了误差，再将“改善”作为结果报告。

## 4. 分布验证：必须使用实测雷达数据

### 4.1 为什么两组仿真不够

只比较 G0 和 G1 的 PDF，可以证明卷浪模块使分布尾部变重或增加海尖峰，但无法判断这种变化是朝真实数据靠近，还是制造了不真实的极端值。理论 K、Weibull 或对数正态分布也不能替代实测数据，因为真实海杂波服从哪种分布会随频段、极化、擦地角、分辨率和海况改变。

因此，分布验证的最小设计是一个实测参照加两组仿真：

| 数据来源 | 内容 | 作用 |
|---|---|---|
| `M_R` | 实测海杂波 | 真实性参照 |
| `G0` | 无卷浪仿真回波 | 消融基线 |
| `G1` | 有卷浪仿真回波 | 完整方法 |

### 4.2 实测数据的匹配条件

`M_R` 与仿真至少要匹配或明确记录：

- 雷达频段和中心频率；
- HH/VV 等极化方式；
- 擦地角和方位角；
- 距离、距离分辨率和脉冲重复频率；
- 海况等级、`U10`、风向和浪向；
- 观测时长、脉冲数和所选距离单元；
- 是否含目标、陆地、船尾迹、雨杂波或系统异常。

不能用 Sea State 5 的仿真去和未知海况的实测片段比较，也不能让三组采用不同的幅度归一化或动态范围。

### 4.3 直接比较指标

分布验证应以实测经验分布为参照，优先报告：

- `KS(M_R, G0)` 与 `KS(M_R, G1)`；
- Wasserstein distance；
- PDF/CDF 的 RMSE 或积分绝对误差；
- `P90`、`P99`、`P99.9` 分位数误差；
- 超阈值概率误差，例如 `P(A > mu + 3sigma)`；
- sea-spike rate 及其相对误差；
- 可选：偏度、峰度和 scintillation index。

核心判据是：

```text
D(M_R, G1) < D(M_R, G0)
```

并且差异在多次随机实现或 bootstrap 置信区间下稳定。对卷浪问题，尾部误差、极端分位数和 sea-spike rate 通常比分布主体的视觉重合更有解释力。

### 4.4 理论分布拟合的正确位置

Rayleigh、Weibull、lognormal、K 或 Pareto 拟合属于辅助分析。可对 `M_R/G0/G1` 使用相同候选族和相同估计方法，再比较：

- AIC/BIC；
- goodness-of-fit；
- 形状参数与尺度参数；
- 尾部拟合误差。

但论文的主问题应是“G1 是否比 G0 更接近 `M_R`”，而不是“G1 是否可以被某个理论分布拟合”。任何随机数据往往都能在若干候选分布中找到相对更好的一个，这本身不能证明仿真真实。

### 4.5 防止数据泄漏

如果散射系数、卷浪强度或分布参数曾依据实测数据调节，必须把实测数据划分为 calibration 和 validation 两部分，或者按不同时间段/海况留出独立验证集。最终表格只用未参与调参的数据，否则“更接近实测”可能只是拟合结果。

## 5. 卷浪破碎判据：必须拆成两层验证

### 5.1 第一层：机制消融，不必使用原始实测数据

若目标只是证明代码中的判据确实控制了卷浪模块，并且卷浪模块产生了预期效果，可使用 `G0/G1` 两组仿真和文献判据完成。

建议指标包括：

- 判据量随时间的变化，例如 `B_x = u/c` 或本文采用的等价量；
- 超过阈值的波峰比例；
- 卷浪模块实际激活比例；
- 判据越阈与几何变换启动之间的时延；
- 随风速/波陡增加，触发率是否单调或呈合理增长；
- G0/G1 的前缘坡度、波峰不对称度、局部曲率和翻卷比例；
- G0/G1 的遮挡面元比例、高 RCS 面元比例和 sea-spike rate。

这层实验可以得出：“卷浪模块只在满足破碎条件时激活，并引起预期的局部几何与散射变化。”

它不能得出：“该阈值准确预测了真实破碎”或“生成的卷浪与真实卷浪一致”。若判据阈值本身也来自同一个模型，再用该模型的输出检查是否超过阈值，会形成循环论证。

### 5.2 第二层：破碎识别准确性，需要带标签的实验或野外数据

如果论文声称本文判据能够准确判断破碎发生，应使用包含真实破碎事件的数据。此时真正的“组别”是带标签的事件，而不是 G0/G1：

| 类别 | 真值 | 用途 |
|---|---|---|
| `B0` | 实验观测为未破碎的波峰 | 统计误报 |
| `B1` | 实验观测为破碎的波峰 | 统计检出和漏报 |

对每个观测波峰计算本文判据，报告：

- sensitivity/recall、specificity、precision 和 F1；
- false alarm rate 与 missed detection rate；
- ROC/AUC，或阈值敏感性曲线；
- 预测破碎时刻相对视频/PIV 真值的 `onset time error`；
- 不同波陡、谱带宽和水深下的稳定性。

若采用能量通量速度与波峰速度之比 `B_x`，文献常报告约 `0.85` 附近的破碎起始阈值；若采用经典运动学条件 `u/c >= 1`，应说明它与局部波峰速度估计、破碎类型和水深的关系。阈值不能脱离判据定义直接互换。

### 5.3 第三层：卷浪几何准确性，需要波面剖面或图像数据

判据正确并不等于生成的卷曲形状正确。若文章强调“准确海面”和“卷浪几何”，至少增加一个可测几何参照：

- 波槽高速摄影提取的自由面轮廓；
- 多时刻二维波面剖面；
- PIV 测得的波峰附近速度场；
- 野外立体摄影/激光测量得到的破碎波面；
- 无法获得原始数据时，可复现实验工况并从公开论文图中数字化剖面，但应明确这是弱验证。

剖面对齐后可报告：

- 自由面轮廓 RMSE/Chamfer distance；
- 波峰高度和前缘坡度误差；
- crest asymmetry ratio；
- 最大曲率及其位置误差；
- jet tip/overturning length 和 plunging angle；
- 首次翻卷时刻误差。

如果模型只是统计海面生成器，不能复现实验的确定性相位过程，可以比较条件统计量：在相同波陡或同类破碎事件下，对波峰对齐、尺度归一化后比较平均轮廓及置信区间。

## 6. 最小可发表方案与增强方案

### 6.1 数据受限时的最小方案

在 GRSL 篇幅和数据都受限的情况下，可采用三项实验：

1. **Cox-Munk 整体物理约束**：`R_C + G0 + G1`，不找额外原始实测数据；报告 MSS-风速曲线、相对误差和置信区间。
2. **卷浪机制消融**：`G0 + G1 +` 已发表破碎阈值，暂不使用原始波槽数据；报告触发率、局部几何、遮挡比例和强散射比例。此处只声称“符合判据并产生合理响应”。
3. **实测海杂波真实性**：`M_R + G0 + G1`；报告 KS/Wasserstein、尾部分位数误差和 sea-spike rate，并用 RTI 作为配套可视化。

该方案只需要寻找一套实测雷达数据，但必须主动限制对卷浪物理准确性的表述。

### 6.2 与“准确卷浪建模”主张匹配的推荐方案

如果“卷浪几何建模”是论文的主要创新点，推荐增加一套公开波槽/野外破碎浪数据：

1. `R_C + G0 + G1`：整体坡度统计；
2. `M_B` 中破碎/非破碎事件 + 本文判据：破碎识别和起始时刻；
3. `M_B` 波面轮廓 + G1：卷浪剖面和局部几何；
4. `M_R + G0 + G1`：海杂波分布和 RTI。

这时文章的证据链才完整：

```text
整体海面统计合理
    -> 破碎判据能识别真实破碎
    -> 卷浪局部几何接近实验观测
    -> 卷浪使雷达回波更接近实测海杂波
```

## 7. 建议直接采用的最终组别

全文统一使用以下命名：

| 编号 | 名称 | 定义 |
|---|---|---|
| `G0` | Proposed w/o breaking | 关闭卷浪模块的本文方法 |
| `G1` | Proposed full | 开启卷浪模块的完整方法 |
| `R_C` | Cox-Munk reference | 坡度统计经验基准 |
| `M_R` | Measured radar clutter | 实测雷达海杂波 |
| `M_B` | Measured breaking-wave data | 实测/实验破碎浪数据 |

不要在不同图中随意改变 G0 的定义。例如，一张图用线性海面作 G0，另一张图又用标准 Lie 变换作 G0，会削弱归因。若确实需要与标准 Lie 方法横向比较，可以增加 `G_base = Standard Lie`，但它是“现有方法基线”，不能替代关闭卷浪模块的消融组。

最终可按以下方式分配数据：

| 验证内容 | `G0` | `G1` | `R_C` | `M_R` | `M_B` |
|---|---:|---:|---:|---:|---:|
| Cox-Munk MSS | 必须 | 必须 | 必须 | 不需要 | 不需要 |
| 幅度分布与重尾 | 必须 | 必须 | 不需要 | 必须 | 不需要 |
| RTI 纹理 | 必须 | 必须 | 不需要 | 必须 | 不需要 |
| 判据机制与消融 | 必须 | 必须 | 文献阈值 | 不需要 | 可选 |
| 判据准确率 | 不适用 | 使用完整判据 | 不需要 | 不需要 | 必须 |
| 卷浪几何准确性 | 可作基线 | 必须 | 不需要 | 不需要 | 必须 |

## 8. 数据寻找优先级

1. **第一优先级：实测雷达海杂波 `M_R`。** 它同时服务于分布、重尾、sea-spike 和 RTI 验证，是雷达论文不可替代的真实性证据。
2. **第二优先级：带自由面轮廓或视频的破碎浪实验 `M_B`。** 它直接支撑文章的卷浪创新点；最好同时包含 breaking/non-breaking 工况。
3. **不需要专门下载 Cox-Munk 原始数据。** 使用原论文或可靠后续文献给出的参数化公式、适用风速和不确定性即可。

寻找 `M_R` 时优先考虑可获得雷达参数、海况和足够长 I/Q 时间序列的数据；寻找 `M_B` 时优先考虑同时给出波面轮廓、时间标定、波速/粒子速度以及明确破碎标签的数据。只有渲染图、没有坐标和实验条件的数据很难形成定量验证。

## 10. 一句话决策

- **Cox-Munk：** 两组仿真对经验曲线，不需要另找原始实测数据。
- **分布验证：** 必须是实测雷达数据加两组仿真，否则不能证明真实性。
- **卷浪判据：** 两组仿真足以做机制消融；若要证明判据准确或卷浪几何真实，必须再找带标签/剖面的实验或野外破碎浪数据。
