# 海面建模、卷浪与雷达回波验证的 Baseline 选择

## 1. 技术结论

当前论文不应寻找一个同时覆盖海面几何、卷浪破碎和雷达回波的“万能 baseline”。现有方法通常只覆盖其中一层。对本文最合理的选择是：

```text
海面几何主 baseline：B1 = Standard Lie / Creamer(2)
海面几何辅助 baseline：B2 = Choppy Wave Model (CWM)
本文消融组：G0 = Proposed without breaking
本文完整组：G1 = Proposed full
外部参考：R = Cox-Munk / 破碎浪观测 / 实测雷达数据
```

如果 GRSL 版面只允许一个外部方法，选择 `B1 = Standard Lie/Creamer(2)`；如果允许两个，增加 `B2 = CWM`。原因是二者都能在与本文相近的计算成本和随机海面场景下复现，而且与海面微波散射研究有直接联系。

对于最终雷达回波，可另外增加一种回波级 baseline：

```text
B_radar-physical = Kudryavtsev breaking-wave NRCS model
或
B_radar-statistical = K-distributed/STCPM/APMO/KMD clutter simulator
```

但回波级 baseline 不能代替海面几何 baseline，因为它们通常不输出三维卷浪表面。

## 2. 前述文献中的方法能否直接作为 Baseline

| 文献/方法 | 有仿真 | 能否作海面几何 B | 能否作卷浪 B | 能否作回波 B | 结论 |
|---|---:|---:|---:|---:|---|
| Rizaev et al. 2022 线性谱面与 SAR 框架 | 是 | 有条件 | 否 | 有条件 | 可作线性弱基线，不足以代表非线性已有方法 |
| Nouguier et al. 2009 CWM | 是 | 是 | 否 | 配合散射模型后可以 | 推荐作为第二外部海面 baseline |
| Barthelemy et al. 2018 三维边界元 | 是 | 不适合作主 B | 参考真值/判据 | 否 | 用于破碎起始和局部物理参考，不适合大场景随机海面比较 |
| McAllister et al. 2023 breaking/non-breaking cases | 是 | 否 | 判据对照 | 否 | 用于阈值和谱带宽敏感性参考，不是可直接复用的 G0/G1 |
| HOS-Ocean/HOS-NWT | 是 | 有条件 | 起始/耗散对照 | 否 | 可作少量高保真数值 baseline，计算和接入成本较高 |
| WAVEWATCH III | 是 | 否 | 统计量对照 | 否 | 用于波谱、耗散、白冠覆盖率等统计参考，不生成翻卷几何 |

### 2.1 Rizaev 线性海面：可以作 B0，但只能作为弱基线

Rizaev et al. 使用线性海面理论、多个波谱和 SAR 成像模型，并把坡度 PDF 与 Cox-Munk 比较。其线性随机海面生成方式容易复现，可以定义为：

```text
B0 = Linear Gaussian sea surface generated by FFT
```

优点：

- 公式和实现简单；
- 可作为代码正确性和最低性能参照；
- 能说明非线性模型相对线性高斯海面的增益。

局限：

- 无波峰-波谷不对称；
- 无局部卷浪和破碎；
- 若只用 B0，对本文 G1 的比较过于容易，审稿人可能认为 baseline 太弱。

因此 B0 可以放在补充实验或可视化中，不能作为唯一外部 baseline。

### 2.2 CWM：可以作 B2，而且是推荐 baseline

Choppy Wave Model 从线性参考面出发，通过 Riesz/Hilbert 变换产生水平位移，能够高效生成二维和三维弱非线性随机海面。Nouguier et al. 2011 在 IEEE TGRS 中将 CWM 与微波散射模型结合，并以 Creamer 模型的 Monte Carlo 结果作为参考测试。

它适合作为本文 baseline，原因是：

- 与本文一样从谱面/随机相位海面出发；
- 可生成非高斯坡度和尖锐波峰；
- 能使用 FFT，适合大场景和多随机种子；
- 已经进入 TGRS 海面 Doppler 与散射研究；
- 论文明确指出 CWM 不描述 near-breaking crests，也不包含 breaking events，因此它恰好代表“有非线性但无显式卷浪”的成熟外部方法。

推荐定义：

```text
B2 = CWM surface + 与本文完全相同的雷达散射和回波合成流程
```

这能回答：完整 G1 是否比一个独立于本文代码的成熟低成本非线性海面模型更接近 Cox-Munk、实测分布和 RTI。

### 2.3 Barthelemy 和 McAllister：不宜作为主 B，但可作为判据 comparator

这两类研究包含数值仿真中的 non-breaking 和 breaking cases，但研究对象是聚焦波群、边缘破碎和破碎起始，而不是给定风速生成的大范围随机海面。

因此不能直接把它们的 non-breaking case 命名为本文 G0，也不能把 breaking case 命名为本文 G1。它们更适合提供：

- `B_x` 类破碎起始量；
- breaking/non-breaking 分类阈值；
- 局部坡度阈值；
- 波峰速度、粒子速度和能量通量的计算方式；
- 谱带宽变化下判据是否稳定的参考结果。

若本文提出了新的触发判据，可设置：

```text
B_criterion-1 = simple local-slope threshold
B_criterion-2 = published B_x criterion
P_criterion   = proposed trigger
R_break       = observed breaking/non-breaking labels
```

若本文只是采用已有 `B_x` 判据而没有提出新判据，则不要把它包装成本文方法的 baseline。此时 `B_x` 是物理先验，真正需要比较的是本文卷曲几何和雷达回波，而不是判据本身。

### 2.4 HOS-Ocean/HOS-NWT：可以有条件作为高保真 B3

HOS-Ocean 是开源高阶谱求解器，HOS-NWT 可模拟数值波槽。相关研究加入破碎起始和能量耗散处理，并用波槽实验验证。

可定义：

```text
B3 = HOS free-surface solution before/onset of breaking
```

适合比较：

- pre-breaking 波面剖面；
- crest height、front-face slope 和 crest speed；
- 破碎起始时刻；
- 非线性谱演化。

不适合直接比较：

- 翻卷后的多值自由面；
- 气泡、飞沫和泡沫；
- 大批量 X 波段训练样本生成效率。

HOS 的势流自由面表达和破碎耗散处理与本文显式三维仿射卷曲不是同一建模层级。建议只选 1-3 个确定性小场景作高保真对照，而不把 HOS 加入所有 Monte Carlo 工况。

### 2.5 WAVEWATCH III：不能作为三维海面 B

WAVEWATCH III 是相位平均谱模型，输出波谱和宏观波浪统计，并包含 whitecapping dissipation。它不保留单个波峰的相位，也不生成可用于面元散射的翻卷自由面。

因此它可以提供：

- 目标海谱；
- 有效波高、峰值周期和方向分布；
- breaking dissipation；
- whitecap coverage 或 breaking probability 的统计参考。

但不能与 G1 做逐点几何、坡度场或面元遮挡比较。论文中应把它标为外部统计参考 `R_stat`，而不是 baseline surface model。

## 3. 新检索到的可用海面生成 Baseline

### 3.1 B1：Creamer(2)/Standard Lie 是最重要的主 baseline

Creamer et al. 的非线性变量变换是海面弱非线性建模的经典方法。后续微波散射研究经常使用 Creamer 或二阶 Creamer 表面，并与线性海面、CWM、West 等模型比较。

它是本文最公平的主 baseline，因为：

- 本文修正方法建立在 Lie/Creamer 类思想上；
- 关闭本文风速驱动、卷浪触发、三维卷曲和遮挡修正后，可以得到清晰的已有方法版本；
- 相比线性海面，Creamer(2) 已能生成更强的二阶非线性；
- TGRS 和海面散射文献把它当作常用数值参考。

推荐定义：

```text
B1 = Published Standard Lie/Creamer(2)
G0 = B1 + 本文除卷浪外的修正
G1 = G0 + breaking trigger + 3-D curling + shadowing
```

如果 G0 与 B1 数学上完全相同，则合并为一个组，不能人为拆成两个名字。

### 3.2 B2：CWM 是独立于本文理论链条的第二 baseline

Standard Lie 与本文有继承关系，单独使用时可能被认为只是“原方法与改进方法”的纵向比较。增加 CWM 的价值是提供一条独立的低成本非线性方法路线。

推荐优先级：

```text
必须：B1 Standard Lie/Creamer(2)
推荐：B2 CWM
可选：B0 Linear FFT
高成本可选：B3 HOS
```

### 3.3 West model 不建议作为当前主 baseline

West 高阶谱类方法曾用于非线性海面和 Doppler 仿真，计算效率可能优于完整 Creamer，但文献也报告其在陡峭表面形成时存在数值稳定性问题。对于强调高海况卷浪的论文，这种失稳会使比较范围难以统一。

除非已有可靠实现和明确的稳定参数，否则不建议为了增加 baseline 数量而重新实现 West model。

### 3.4 Stokes/Gerstner 只适合确定性剖面辅助比较

Stokes 二阶/五阶波和 Gerstner 波能够提供经典非线性周期波剖面，但不是面向给定风速和方向谱的大范围随机海面模型。

它们适合：

- 单波剖面可视化；
- crest-trough asymmetry 检查；
- 代码单元测试；
- 特定波陡下的局部几何参考。

不建议将其作为全文随机海面主 baseline。

## 4. 新检索到的雷达回波 Baseline

## 4.1 Kudryavtsev 模型可作为物理回波 baseline

Kudryavtsev et al. 的半经验海面 NRCS 模型把雷达回波分成：

```text
regular/non-breaking surface contribution
+ breaking-zone non-Bragg contribution
```

其中普通海面采用复合 Bragg 思路，破碎贡献与 breaking-front statistics 或增强粗糙度覆盖比例相关。模型在多频段、风速、入射角和极化条件下与观测 NRCS 比较。

它很适合作为：

```text
B_radar-physical = Kudryavtsev/KHCC NRCS
```

可以比较：

- NRCS 随风速变化；
- NRCS 随入射角/擦地角变化；
- HH/VV 极化比；
- upwind/downwind ratio；
- 加入 breaking contribution 前后的增益。

不能直接比较：

- 三维卷浪几何；
- 单次 realization 的 RTI 纹理；
- range-time 联合相关性；
- 逐个卷浪的遮挡位置。

因此，KHCC 应作为“聚合 NRCS 物理 baseline”，不能替代 B1/CWM 海面模型。

### 4.2 Ericson 实验适合作为 X 波段 breaking-return 参考，不是 baseline 算法

Ericson et al. 对固定破碎浪进行了 X 波段 HH/VV 测量，并用不同散射近似解释破碎波峰附近增强回波。其结果可以作为：

- 破碎波峰附近 NRCS 增强的数量级参考；
- HH/VV 极化比趋势参考；
- 小扰动法、积分方程法等散射近似的适用性参考。

这是实验与数值散射基准，不是可直接生成大范围海杂波的 baseline。

### 4.3 K-distribution/STCPM 可作为统计回波 baseline

STCPM 将海杂波建模为具有时空相关性的复合 K 分布过程，可重建幅度分布、时间相关和空间相关。经典对照还包括：

- `ZMNL`：zero-memory nonlinear transform；
- `SIRP`：spherically invariant random process；
- `TCM`：temporal-correlated method；
- `SCM`：spatial-correlated method；
- `STCPM`：spatial-temporal correlated proportional method。

推荐使用：

```text
B_radar-stat = STCPM 或 correlated K-distributed simulator
```

它可以回答：本文物理海面到回波的方法，在 PDF/CDF、ACF、空间相关和 Doppler 方面能否达到传统统计模拟器的拟真水平。

但统计模型通常使用实测数据估计分布与相关参数。若本文 G1 不使用同等实测信息，必须说明数据使用差异，不能简单以误差大小宣称全面优越。

### 4.4 TGRS 数据驱动模型可作为“数据拟合上界”，但不是公平主 baseline

近年 TGRS 中可选的回波级数据驱动方法包括：

- KMD/Koopman mode decomposition 海杂波模型；
- APMO 类二维幅相匹配优化方法；
- arbitrary-distribution spatial-temporal correlated simulation。

这些方法直接从实测海杂波学习时空模式、幅度和相位，通常在复现实测统计方面很强。它们适合作为：

```text
B_radar-data = data-driven upper-reference baseline
```

比较价值：

- 展示纯数据驱动方法的统计拟真上限；
- 对比本文方法在物理可控性、外推风速/风向和不依赖大量训练数据方面的优势。

局限：

- 需要训练/拟合实测数据；
- 可能记忆特定雷达和海况；
- 不生成可解释三维海面；
- 与本文“数据稀缺条件下的物理仿真”目标不同。

因此不建议把数据驱动模型作为海面建模部分的主 baseline。若篇幅允许，可在最终回波分布表中增加一列，并明确标注其使用了实测训练数据。

## 5. 推荐的最终 Baseline 组合

### 5.1 GRSL 最小可行组合

推荐正文只保留：

```text
R_CM     = Cox-Munk
B1       = Standard Lie/Creamer(2)
G0       = Proposed without breaking
G1       = Proposed full
R_radar  = NAV measured clutter
```

对应实验：

| 实验 | 参照与组别 | 主要结论 |
|---|---|---|
| Cox-Munk | `R_CM/B1/G0/G1` | G1 是否比已有 Lie 和消融组更接近整体坡度统计 |
| 卷浪局部几何 | `B1/G0/G1 + breaking reference` | G1 是否增加合理的波峰前倾、曲率和翻卷结构 |
| 回波分布/RTI | `R_radar/B1/G0/G1` | G1 是否改善重尾、海尖峰和时距纹理 |

这里 B1、G0、G1 的回波必须使用同一个散射与信号处理链，才能把差异归因于海面模型。

### 5.2 更强但仍可控制篇幅的组合

若版面允许，再增加：

```text
B2 = CWM
```

此时正文核心比较为：

```text
Standard Lie / CWM / G0 / G1 / Reference
```

这比加入线性海面更有价值，因为 Standard Lie 和 CWM 都是成熟弱非线性方法，审稿人更难质疑 baseline 过弱。

### 5.3 适合补充材料或后续 TGRS 长文的组合

可增加：

- HOS-NWT 小场景；
- KHCC NRCS 曲线；
- STCPM 或 KMD 回波统计 baseline；
- 线性 FFT 海面；
- 阈值敏感性和计算时间比较。

不建议在 GRSL 正文同时放入所有方法，否则每个 baseline 的参数公平性难以解释，并会挤压实测验证篇幅。

## 6. 公平复现 Baseline 的关键条件

### 6.1 使用相同环境输入

B1、B2、G0、G1 应共享：

- 相同目标方向谱和风速；
- 相同波数范围 `k_min/k_max`；
- 相同网格、区域尺寸和时间步长；
- 相同随机相位；
- 相同水深和色散关系；
- 相同 Monte Carlo 种子数；
- 相同雷达散射与回波处理流程。

### 6.2 非线性模型会改变输出谱，必须检查 spectrum matching

CWM、Creamer 和本文变换都会使输出的“dressed spectrum”偏离输入参考谱。如果直接给所有方法同一输入谱，最终输出能量可能不同，雷达回波差异不一定只来自卷浪几何。

建议做两套协议：

1. **Same-input protocol：** 所有方法使用同一输入谱和随机相位，比较完整算法效应；
2. **Spectrum-matched protocol：** 调整各方法参考谱，使最终输出 PSD、显著波高和主周期一致，再比较坡度高阶统计、卷浪几何和雷达回波。

主文建议使用 spectrum-matched 结果，same-input 结果作为敏感性分析。至少应报告每组最终 PSD 或谱矩误差，避免 G1 仅通过增加总能量获得更强海尖峰。

### 6.3 复现已有方法后先做实现验证

在将自编 baseline 用于论文比较前，至少复现原论文中的一个结果：

- Creamer/CWM 的坡度 PDF 或非高斯矩；
- TGRS 文献中的 Doppler shift/bandwidth 趋势；
- HOS 的标准算例；
- KHCC 的 NRCS-风速或 NRCS-入射角曲线；
- STCPM 的 PDF 与时空相关函数。

否则审稿人可能认为 baseline 表现差是由于本文复现错误。

### 6.4 不能让 baseline 使用更少的信息后直接宣称全面优越

不同方法的信息输入必须写清楚：

| 方法 | 是否使用实测数据拟合 | 是否输入海谱 | 是否生成三维海面 | 是否显式破碎 |
|---|---:|---:|---:|---:|
| Standard Lie | 否 | 是 | 是 | 否 |
| CWM | 否 | 是 | 是 | 否 |
| G0 | 否 | 是 | 是 | 否 |
| G1 | 否/视参数来源 | 是 | 是 | 是 |
| STCPM/KMD/APMO | 是 | 通常否 | 否 | 隐式 |

数据驱动 baseline 更接近同一实测序列是预期结果；本文应强调条件可控性、物理解释和跨海况生成，而不是只比较单一拟合误差。

## 7. 每类 Baseline 对应的指标

| Baseline | 应比较的指标 | 不应据此声称的结论 |
|---|---|---|
| Linear FFT | PSD、MSS、坡度 PDF | 不能证明优于成熟非线性模型 |
| Standard Lie/Creamer(2) | MSS、slope PDF、crest asymmetry、回波重尾 | 不能单独验证破碎判据准确 |
| CWM | 非高斯坡度、计算时间、Doppler/RTI | 不能比较真实翻卷后的流体细节 |
| HOS | pre-breaking profile、onset time、crest speed | 不能直接作为泡沫/飞沫真值 |
| KHCC | NRCS、极化比、方位比 | 不能比较三维面元几何和单次 RTI |
| STCPM/KMD/APMO | PDF/CDF、ACF、空间相关、Doppler | 不能证明海面物理结构正确 |

建议提前指定主指标：

- 海面总体：Cox-Munk total-MSS NRMSE；
- 海面方向性：upwind/crosswind MSS NRMSE；
- 非线性几何：slope-PDF Wasserstein distance、crest asymmetry；
- 卷浪：onset error、breaking occurrence、profile error；
- 雷达：tail error、P99/P99.9、sea-spike rate、ACF 和 Doppler；
- 工程性：单帧/单位时长生成时间和内存。

## 8. 最终执行建议

### 正文必须实现

1. `B1 Standard Lie/Creamer(2)`；
2. `G0 Proposed without breaking`；
3. `G1 Proposed full`；
4. Cox-Munk 和 NAV 实测参照。

### 正文推荐增加

5. `B2 CWM`，作为独立低成本非线性海面 baseline。

### 暂不建议作为正文必需项

6. HOS-Ocean/HOS-NWT：放补充材料或小场景；
7. KHCC：仅在增加 NRCS 角度/风速曲线时使用；
8. STCPM/KMD/APMO：仅在强调最终数据生成能力时使用；
9. WAVEWATCH III：作为统计参考或环境输入，不作为三维海面 baseline。

最精炼、最有说服力的正文分组是：

```text
Cox-Munk / measured reference
Standard Lie
CWM
Proposed w/o breaking
Proposed full
```

如果版面必须压缩，删除线性海面和 CWM 中的一项时，应优先删除线性海面，保留 Standard Lie。
